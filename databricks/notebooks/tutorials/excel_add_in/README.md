# Azure Databricks Excel Add-in

Tutorial paso a paso para probar el Azure Databricks Excel Add-in con una tabla demo en Databricks.

La idea es mostrar cómo conectar Excel con datos gobernados en Databricks, importar tablas, ejecutar queries SQL y crear análisis desde Excel sin exportar CSVs manualmente.
